Techniques and model

Two ways to protect data

You can transform a message to make it secure. Or you can hide the message inside something else.

Data security techniques

Cryptography

“Cryptography means secrete writing.”

“It refers to the art of transforming messages to make them secure and immune to attacks.”

“It involves three distinct mechanisms: symmetric-key encipherment, asymmetric-key encipherment, and hashing.”

Secrete: secret. Immune to: safe from. Distinct mechanisms: separate tools. Encipherment: turning a message into secret code.

Steganography

“Steganography means covered writing.”

“It refers to concealing the message itself by covering it with something else.”

“It is possible to insert secrete binary information into data during digitization process.”

Concealing: hiding. Binary: made of 0s and 1s. Digitization: turning something into digital data.

Steganography · text cover

Hiding bits in spaces

Objective: “It hides information either for secrecy or to protect copyright, prevent tampering or add extra information.”

Secrecy: keeping something secret. Copyright: the owner’s right over a work. Tampering: changing something without permission.

Text cover: “We can use single space between words to represent bit 0 and double space to represent bit 1.”

Represent: stand for.

Example: “Consider the ASCII code of letter A: 01000001.”

This▽0course▽▽1is▽0intended▽0to▽0provide▽0data▽0security▽▽1basics.

Your slides’ sentence. Each ▽ is one space.

Step 1: read each gap. One space gives 0. Two spaces give 1.

Step 2: the 8 gaps give 01000001: the code of A.

Try: which bits does “Meet▽▽me▽at▽▽noon” hide?

Answer: two, one, two spaces: 101.

Steganography · image cover

Hiding bits in an image

“Secrete data can be covered under a color image.”

“Images are made of pixels, each of 3 bytes.”

“In LSB method, LSBs are set to 0s.”

“The ASCII code of the character is inserted in LSBs.”

LSB: least significant bit, the last bit on the right of a byte. Inserted: put in.

Example: “Consider the ASCII code of letter M: 01001101.” “This can be hide in 3 pixels.”

Be hide: be hidden.

Pixel 1010100111011110001010101
Pixel 2011001011011110001011110
Pixel 3000101010100101001111110

Your slides’ 9 bytes, in the order the slide lists them. The marked last bit of each byte is its LSB. our grouping Three bytes per pixel.

Step 1: 3 pixels × 3 bytes = 9 LSBs. The 8 bits of M need 8 of them.

Step 2: the first 8 LSBs read 10110010: M’s code 01001101 from its last bit to its first.

Step 3: the last of the 9 LSBs stays 0.

Security model Asked in your slides

Three components

Your slides ask: “List the three components of the Security System?” Their answer:

1 “A security-related transformation of information to be sent. Examples include:

  • Encryption of message to be unreadable by opponent.
  • Addition of a code to verify the identity of the sender.”

2 “Some secret information shared by the two principals and unknown to the opponent. An example is an encryption key.”

3 “A trusted third party for distributing secret information to the two principals.”

Unreadable: cannot be read. Verify the identity: check who it really is. Trusted: relied on. Distributing: giving out.

Security model

Four basic security tasks

Four Basic Security Tasks
1“Design an algorithm for performing the security-related transformation.→ component 1
2Generate the secret information to be used with the algorithm.→ component 2
3Develop methods for the distribution and sharing of the secret information.→ component 3
4Specify a protocol for principals to use security algorithm and secret information to achieve security service.”→ all three

Generate: make. Distribution: giving out. Specify: state exactly. Protocol: a set of rules the parties follow. Achieve: reach.

“Ingredients of Symmetric-key Cryptography

  1. Plaintext The original message that is fed into the algorithm as input.
  2. Encryption algorithm It transforms the plaintext to a ciphertext.
  3. Secret key Transformations performed depend on that key.
  4. Ciphertext It is the scrambled message produced as output.
  5. Decryption algorithm It is the encryption algorithm run in reverse to produce plaintext from the ciphertext.”

Fed into: given to. Scrambled: mixed up so it cannot be read. In reverse: the other way round. Recipient: receiver.

Notice: one secret key feeds both algorithms.

Symmetric-key

Six properties

“Properties

  1. It was the only type of encryption in use till the late 1970s.
  2. The encryption and decryption keys (Ke), (Kd) are the same and should be kept secrete.
  3. It is also referred to as conventional encryption, secret-key, or single-key encryption.
  4. The Decryption algorithm is the inverse of the Encryption algorithm.
  5. Any one who knows the encryption algorithm and key can deduce the decryption algorithm.
  6. For m users, the number of required keys is [m×(m-1)]/2.”

Till: until. Referred to as: called. Inverse: the opposite. Deduce: work out.

KeKd
Common mistake: thinking Ke and Kd differ. In symmetric-key encryption they are the same.
Symmetric-key

How many keys?

our picture AB CD
[m×(m-1)]/2m = the number of users

How to read it: m times (m minus 1), then divided by 2.

Worked example: 4 users, A to D.

  1. 14 × (4 − 1) = 4 × 3 = 12.
  2. 212 ÷ 2 = 6 keys.

Why it works (our reading): each pair of users shares one key. Each user pairs with m − 1 others. Each pair is counted twice, so we divide by 2.

Try: 5 users?

Answer: 5 × 4 = 20. 20 ÷ 2 = 10 keys.

Block and stream ciphers

Block cipher

“A block of plaintext symbols of size m (m > 1) are encrypted at a time creating a block of ciphertext of the same size.”

“The block size is usually a multiple of 64 bits.”

“A single key is used to encrypt the whole block even if the key is made of multiple values.”

Symbols: characters or bits. m > 1: m is more than 1. A multiple of 64: 64, 128, 192 and so on. Multiple values: several parts.

Notice: m bits in, m bits out, one key.

Block and stream ciphers

Stream cipher

“It processes the input elements continuously, producing one symbol (a character or a bit) at a time, as it goes along.”

“There are plaintext stream, cipher stream, and key stream.”

“Stream ciphers are more immune to the corruption of bits during transmission.”

“They are faster than block ciphers.”

“Their hardware implementation is easier.”

Input elements: the pieces that go in. Continuously: without stopping. Corruption of bits: bits damaged. Hardware implementation: building it in hardware.

Notice: a block cipher takes m symbols at a time. A stream cipher gives one symbol at a time.

Back to the question

The class group chat

Ali sends Sara a door code in a group chat that others read. Plan 1 mixes up the code with a secret rule. Plan 2 hides it in a normal sentence. Which plan can hide that a secret exists?

A

Plan 1, the mixed-up code.

Plan 1 is cryptography: “the art of transforming messages to make them secure and immune to attacks.” The others still see the mixed-up code.

B

Plan 2, the normal sentence.

Plan 2 is steganography: “concealing the message itself by covering it with something else”, like single and double spaces.

C

No plan. People always notice a secret.

Steganography hides the message itself, so others can miss it.

If Plan 1 uses symmetric-key encryption, Ali and Sara share the same secret key.
